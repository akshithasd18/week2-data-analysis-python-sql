Week 2 – Data Analysis Assignments

This repository contains my Week 2 assignments for Python and SQL for Data Analysis.

Python for Data Analysis

The Python assignment covers the following topics:

1. Load a CSV file using Pandas and display basic information.
2. Handle missing values and duplicates using Pandas.
3. Group data by category and find total revenue.
4. Sort data by multiple columns using Python.
5. Create a correlation matrix for numerical columns.

SQL for Data Analysis

The SQL assignment covers:

- Basic queries using SELECT and WHERE
- GROUP BY and ORDER BY
- Aggregate functions: SUM, AVG, COUNT
- Joins
- Subqueries
- CASE statements
- Finding top customers
- Calculating average order values

Files Included

- "python_practice.ipynb" – Python assignment solutions.
- "week2_queries.sql" – SQL assignment solutions.
- "sales_data.csv" – Dataset provided for the assignment.
